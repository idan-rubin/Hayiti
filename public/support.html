Help with Hayiti

Start a journal

Open the journal and choose New trip. Enter a name and dates. Sign in with ChatGPT to keep changes between visits.

Try a sample trip

In an empty journal choose Try the sample trip. To add it next to your own trips, download the Tel Aviv example, choose Sources and import, select the JSON file and confirm. Open the list view to move a stop. The example includes card receipts, a taxi ride and a calendar event. Taxi locations are approximate.

Use the ChatGPT plugin

Once installed, ask Hayiti to list your trips, show the stops on a particular day, or save places and dates you provide. When using information from another source, select and approve the itinerary details you want saved.

Remove a trip

Select the trip and open Trip settings. Choose Delete trip and confirm. Export a backup first if you want a copy.

Contact the developer

For help or privacy requests, email Idan Rubin at rubin.idan@gmail.com. Include the name of the feature and what happened. Please leave personal trip records and account credentials out of support messages. You can also report a bug in the Hayiti repository on GitHub, where issues are public.
