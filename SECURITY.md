# Security

Please report vulnerabilities privately to the maintainer through the contact address on the [hayiti support page](https://hayiti-beta.cocoacoati256.chatgpt.site/support.html). Include the affected version, observed impact and a minimal example using fictional travel data. Keep account details, receipts, route URLs and access tokens out of public issues.

The hosted adapter requires an identity verified by the hosting platform. Configure object storage so only the server can access it. Treat a shared route URL as a bearer credential. Revoking it stops future reads from the service. Downloaded copies remain with recipients.
